# CRTM Exam Report Template for SysReptor

A custom SysReptor report template for the Certified Red Team Master(CRTM) exam by Altered Security.

It includes:

- Custom CRTM-style report layout
- Cover page with logo and cover image
- Structured report sections for attack, defense, and cleanup documentation
- Machine walkthroughs implemented through SysReptor findings
- Severity table support for machine walkthrough fields

## Usage

- Download the archive from [Releases](https://github.com/0xJavlonbeck/CRTM-Report-Template/releases)
- In SysReptor, open `Designs`
- In `Import File` Select the downloaded archive
- Choose this design when creating a new project
- Write machine walkthroughs in `Findings`
